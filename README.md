# AI-Powered Placement and Salary Predictor

B.Tech CSE (AI/ML) project exhibition submission. Predicts (1) whether a student is likely to
be placed, and (2) their expected salary package, using academic and employability features.

## Status
🔲 Phase 1 (Dataset Analysis) — in progress. See `PROJECT_CONTEXT.md` for full project history,
decisions, and current blockers.
